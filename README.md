## О проекте

Репозиторий содержит лабораторные работы №5–7, объединённые одной предметной областью — автоматизацией службы такси. Приложение написано на C# и ASP.NET Web Forms, хранит данные в MySQL и предоставляет отдельные сценарии для пассажира, водителя и диспетчера.

Пользователь может зарегистрироваться, войти в систему, изменить профиль, создать поездку, следить за активными заказами, просматривать историю и оставлять отзывы. Водитель принимает доступные заказы и завершает поездки. Диспетчер работает с заказами, пользователями, тарифами и выборками по данным автопарка.

## Лабораторные работы

### Лабораторная работа №5 — работа с базой данных

- подключение веб-приложения к базе данных MySQL;
- авторизация пассажиров и сотрудников;
- отображение данных службы такси;
- выборка автомобилей по марке и году выпуска;
- просмотр поездок выбранного автомобиля;
- работа с параметризованными SQL-запросами и элементами `GridView`.

### Лабораторная работа №6 — личный кабинет пассажира

- регистрация и вход в учётную запись;
- просмотр и редактирование профиля;
- создание заказа с выбором начального и конечного адреса;
- расчёт стоимости поездки;
- просмотр активных заказов;
- отмена заказа;
- история завершённых и отменённых поездок;
- добавление оценки и текстового отзыва.

### Лабораторная работа №7 — кабинеты сотрудников

- разделение интерфейса по ролям водителя и диспетчера;
- просмотр и принятие водителем свободных заказов;
- контроль одной активной поездки у водителя;
- завершение или отмена поездки;
- просмотр истории поездок водителя;
- создание и отмена заказов диспетчером;
- редактирование пользователей и водителей;
- настройка городов и тарифов;
- выполнение выборок по данным автопарка.

Код лабораторных работ №5–7 находится в ветке `main`.

## Запуск проекта

### Требования

- Windows;
- Visual Studio 2022 с компонентом **ASP.NET and web development**;
- .NET Framework 4.7.2 Developer Pack;
- MySQL Server;
- NuGet.

### Настройка

1. Клонируйте репозиторий и перейдите в его каталог:

   ```bash
   git clone https://github.com/Diminasss/taxiDiminasAspNet.git
   cd taxiDiminasAspNet
   ```

2. Откройте решение `Lab5.sln` в Visual Studio.

3. Восстановите NuGet-пакеты через **Restore NuGet Packages**.

4. Создайте в MySQL базу данных `taxi`. Приложение ожидает таблицы пассажиров, сотрудников, водителей, автомобилей, адресов, поездок, статусов, тарифов и отзывов. SQL-дамп схемы в репозитории отсутствует, поэтому структуру базы необходимо подготовить отдельно.

5. Укажите собственные параметры подключения в секции `connectionStrings` файла `Web.config`:

   ```xml
   <connectionStrings>
     <add name="TaxiDB"
          connectionString="server=localhost;user id=YOUR_USER;password=YOUR_PASSWORD;database=taxi;charset=utf8"
          providerName="MySql.Data.MySqlClient" />
   </connectionStrings>
   ```

6. Выберите профиль IIS Express и запустите проект клавишей `F5`.

## Основные статусы поездки

В серверной логике используются следующие идентификаторы статусов:

| ID | Состояние |
|---:|---|
| 1 | Новый заказ, ожидающий водителя |
| 2 | Поездка выполняется |
| 3 | Поездка завершена |
| 4 | Поездка отменена |

## Учебное назначение

Проект демонстрирует разработку многостраничного веб-приложения на ASP.NET Web Forms, взаимодействие с реляционной базой данных, разграничение пользовательских ролей, хранение состояния в сессии и реализацию CRUD-операций средствами ADO.NET.
